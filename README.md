# 📋 Meu Primeiro Projeto em Python

Meu primeiro sistema real em Python! Um gerenciador de listas bem simples onde você cria listas e adiciona/remove itens.

## 🎯 O Que Faz

- Criar listas com nomes personalizados
- Adicionar/remover itens (sem duplicatas)
- Ver todos os itens de uma lista
- Menu fácil de usar

## 🚀 Como Rodar

```bash
python3 main.py
```

## 📝 O Que Aprendi

- **Organização**: Separar código em módulos (functions e menus) ao invés de tudo em um arquivo
- **Estruturas de dados**: Dicionários e listas aninhadas
- **Loops e condições**: `while`, `for`, `if/else`
- **Match/Case**: Nova forma legal de fazer seleções de menu
- **Funções**: Reutilização de código ao invés de copiar
- **Validações**: Checar se item já existe, se lista existe, etc
- **f-strings**: Formatação de texto com variáveis
